# QA Automation

Playwright + k6 QA automation suites for client websites, one project per client under `Projects/`, with shared documentation in `Shared/`.

**Picking this up? Read [HANDOVER.md](HANDOVER.md) first.** It covers the state of every project, open work and known gotchas.

Then see [Shared/README.md](Shared/README.md) for setup and onboarding, and [Shared/docs/new-project-checklist.md](Shared/docs/new-project-checklist.md) when adding a new client suite.
